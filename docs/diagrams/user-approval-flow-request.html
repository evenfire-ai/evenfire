Flow A — Approval Request Lifecycle

coordinator Pod requests approval → control-api validates → poll until terminal state

Step Gating

  • coordinator.ts detects requiresApproval in the ConfigMap
  • Pauses before dispatch to mcp-host
  • approvalRequester.gateStep() blocks until terminal
  • denied/expired → marks step failed + reports to WRC
  • approved → resumes and executes the step normally

Idempotency

  • Idempotency-Key: sha256(recipe:stepId:runId)
  • Unique index on (recipeNs, recipeName, idempotency_key)
  • 409 when key already exists → returns existing approvalRequestId
  • Protects against coordinator Pod restarts

Expiry Cron

  • setInterval(60_000) inside control-api
  • UPDATE status='expired' WHERE pending AND expires_at < now()
  • Idempotent: reruns do not change terminal rows
  • Max delay: 60s between expiration and detection
