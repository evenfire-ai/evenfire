# Desktop UI UX Docs

This folder is the source of truth for desktop UX decisions, with a focus on end-user clarity and low-friction workflows.

## Product Positioning

- `control-ui` is for admins configuring hosts, agents, teams, users, and permissions.
- `desktop-app` is for non-technical end users (PM, BD, operators) who need a simplified experience.
- Desktop UX should hide setup complexity and expose only what users need to do their work.
