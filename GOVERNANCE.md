# Governance

evenfire is maintained by Keyper Labs. Direction is set by the core maintainers.

## Proposing changes

Open an issue describing the problem before large PRs. Maintainers triage
regularly and label accepted work `good first issue` / `help wanted` where
suitable. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Decision making

Maintainers decide by lazy consensus; the core team has final say on scope and
roadmap. This is a single-vendor source-available / open-core style project, not
a foundation.
