# Governance

evenfire is maintained by Keyper Labs. Direction is set by the core maintainers.

## Proposing changes
Open an issue describing the problem before large PRs. Maintainers triage weekly
and label accepted work `good first issue` / `help wanted` where suitable.

## Decision making
Maintainers decide by lazy consensus; the core team has final say on scope and
roadmap. This is a single-vendor open-core project, not a foundation.
