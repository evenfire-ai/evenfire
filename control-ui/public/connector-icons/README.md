# Marketplace connector icons

SVGs are bundled locally; no icon CDN is contacted when the marketplace renders.
`sources.json` records exact download URLs and each provider's attribution and
license metadata, obtained using the Dashboard Icons plugin on 2026-11-26.
Dashboard Icons assets: Apache-2.0 (see LICENSE-dashboard-icons.txt).
LobeHub assets: MIT (see LICENSE-lobehub.txt).
Firecrawl: Icons by selfh.st/icons, CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/), downloaded unchanged.
arXiv, Dovetail, HubSpot, Paddle, Square and Model Context Protocol:
Simple Icons, CC0-1.0. Brand marks remain subject to their owners' terms.

The original capability pictograms (book, brain, browser, chain, chart, clock,
coins, folder, globe, identity, steps and users) use this repository's license.
These cover services without matching brand SVGs in the catalog. GitMCP uses
the Git logo. Microsoft Learn uses the Microsoft logo. No substitute brand
logos are used for fuzzy matches such as Monid/Monit.

The friendly-name mapping covers 55 distinct registry identifiers from the
60-version public catalog. Duplicate versions are intentionally retained.

CoinGecko, Etherscan and DeFiLlama SVGs were supplied by the user on
2026-11-26 and are preserved unchanged.

HeyReach uses the user-provided HeyReach_Icon-Primary-Dark.svg, preserved unchanged.

Playwright uses the user-provided playwright-logo.svg, preserved unchanged.

Stripe, Linear and Perplexity assets are recolored to black for light mode
and white for dark mode, retaining the original SVG geometry.
