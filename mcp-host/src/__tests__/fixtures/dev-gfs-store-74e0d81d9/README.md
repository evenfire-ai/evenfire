# Volume state written by the pre-#1028 GFS download store

Generated by running the real store of dev `74e0d81d9`, not written by hand:

```bash
# Node 24 on PATH, from the repository root
scripts/dev/gfs-store-rollback-check.sh --write-fixture
```

- `crashed/` is a Host root after the dev store wrote two completed records, one
  record marked `missing` (its copy was rewritten), one `transferring` record, an
  expired processing lease and a live one, and its process was killed.
- `restarted/` is `crashed/` after the dev Host startup (`bootstrapGfsRuntime`)
  reopened it and stopped: every record `quarantined`, the inherited leases kept,
  and the store unavailable (#1019).
- `generation.json` records the commit, the generation time, the record states,
  the lease ids and the mode of every entry.

Two normalisations, both undone by `../devGfsStoreFixture.ts` when it copies a
snapshot: `writer.lock` names device and inode `"0"` (the loader writes the
identity of the copied `writer-v2.sqlite`), and ledger timestamps are shifted by
the time elapsed since `generatedAtMs`, so the live lease is still live.
